# Por que confirmamos a identidade antes de responder

Para nao entregar dados de uma pessoa a outra, o encarregado so responde depois de confirmar que o pedido e do proprio titular.

Como funciona:

- o pedido e registrado pelo chat, sem nenhum dado pessoal na resposta;
- a confirmacao usa um codigo de verificacao enviado por WhatsApp para o numero cadastrado no atendimento;
- o chat nunca pede CPF, documento ou foto;
- se o titular nao confirmar, o caso fica pausado aguardando o titular.

Pedidos sobre dados de outra pessoa (parente, vizinho, conjuge) nao sao atendidos pelo chat: vao para o encarregado, que avalia se ha base legal para qualquer resposta.
